# Sheet Printer

Open any PDF, repeat it on any paper size at its real size, preview, and print.

Features: fill page automatically or custom copies, gaps, margin, crop marks,
rotation (0/90/180/270/auto best fit), custom paper size, mm/cm/inch,
page selection for multi-page PDFs, Save PDF, Print, and an Update button.

## Put it on GitHub (no coding needed)
1. Log in to github.com as adibuddin905-web.
2. Click "+" (top right) > New repository. Name: sheet-printer. Choose PUBLIC
   (the Update button needs a public repo). Click Create repository.
3. Click "uploading an existing file". Open the unzipped folder, select
   EVERYTHING inside it (including the hidden-looking ".github" folder) and
   drag it into the browser. Click Commit changes.
4. Right side > Releases > Create a new release. In "Choose a tag" type v1.0.0
   and click Create new tag. Title: v1.0.0. Click Publish release.
5. Click the "Actions" tab. Wait about 3-5 minutes for the green tick.
6. Go back to Releases > v1.0.0 > download SheetPrinter.exe. Double-click it.
   (Windows may say "unknown publisher": click More info > Run anyway.)

## Updating later
1. Change a file on GitHub (open the file > pencil icon > Commit changes).
2. Create a new release with a higher tag, e.g. v1.0.1 (wait for the green tick).
3. Open the app and click Update. It downloads and restarts itself.
